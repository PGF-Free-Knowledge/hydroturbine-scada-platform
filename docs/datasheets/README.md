# Datasheets and Technical Documentation

This directory contains all technical documentation associated with the HydroTurbine-SCADA platform.

# Objective

Centralize engineering documentation for:

- Siemens PLC systems
- SCADA/HMI platforms
- Sensors and instrumentation
- Hydraulic systems
- Mechanical components
- Industrial communications
- Power supplies
- PID control systems
- Turbine Pelton and Francis instrumentation
