# Francis Turbine Automation System

## Overview

This section contains the engineering documentation, industrial control concepts, SCADA integration architecture and instrumentation associated with the Francis turbine system within the HydroTurbine-SCADA platform.

---

# Main Objectives

The Francis turbine project focuses on:

- Torque monitoring
- RPM supervision
- Hydraulic brake control
- PID control strategies
- Industrial SCADA integration
- Real-time data acquisition
- Industrial communication systems
- Process analytics and supervision

---

# System Architecture

The Francis turbine system integrates:

- Siemens S7-1200 PLC
- Industrial SCADA systems
- Hydraulic control systems
- Torque monitoring
- Encoder-based RPM acquisition
- Industrial Ethernet communication
- Python-based monitoring and analytics
