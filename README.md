# HydroTurbine SCADA Platform

Sistema de monitoreo, control y visualización SCADA
para turbinas hidráulicas Pelton y Francis.

## Tecnologías

- Siemens S7-1200
- Python
- Node-RED
- Grafana
- SCADA/HMI
- Modbus TCP
- Profinet

## Objetivos

- Digitalización industrial
- Monitoreo en tiempo real
- Registro histórico
- Alarmas
- Dashboards
- Analítica de datos
- Escalabilidad Industry 4.0
